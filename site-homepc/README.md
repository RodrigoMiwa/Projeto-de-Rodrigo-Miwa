# Site institucional - TechPro

Projeto inicial de site institucional inspirado na arquitetura de navegação de empresas de suporte e infraestrutura de TI.

## Estrutura

- `index.html` — página inicial
- `pages/sobre.html` — sobre a empresa
- `pages/servicos.html` — serviços
- `pages/clientes.html` — clientes
- `pages/contato.html` — contato
- `assets/css/style.css` — estilos e responsividade
- `assets/js/main.js` — interações
- `assets/images/` — imagens e identidade visual
